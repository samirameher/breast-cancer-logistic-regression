# Breast Cancer Prediction Using Logistic Regression

This project uses logistic regression to predict breast cancer malignancy based on patient tumor characteristics.

## Highlights
- Dataset from Kaggle with 569 samples and 32 features
- Feature selection using correlation filtering
- Achieved 95.88% accuracy, 97.14% recall, 0.996 AUC-ROC

## Tools & Methods
- R
- Logistic Regression
- Model Evaluation (Precision, Recall, AUC)
